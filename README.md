GOOOOBY

- A bot made in python using the Bolt for Python framework included with the slack cli for making bots

Its made to keep project ideas organized in a nice list that you can easily access from your slack

Only one / command right now being /add_idea which lets you type out an Idea and let it get added to the bots home tab

The home tab simply displays a list of all the ideas you added to it as shown below

Anyone wanting to run this bot locally will have to download the slack cli and run slack create to make a new bot then slack run to actually locally run the bot
